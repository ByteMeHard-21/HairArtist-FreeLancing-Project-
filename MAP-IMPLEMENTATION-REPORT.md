# Location map implementation report

## Scope and architecture

Replaced the homepage Location panel's placeholder/optional iframe with a real MapLibre map. The project uses npm, Next.js 16.3.5 App Router, React 19, strict TypeScript and Tailwind 4 with existing custom CSS. The homepage and Location section remain server components. Only `LocationMap` is a client component, and the renderer is dynamically imported near the viewport.

The left information card, its CTAs, the caption, desktop two-column layout, existing mobile map-first order, typography, colors and unrelated sections were preserved. The map canvas has a 350px minimum height on larger screens and 300px on mobile; it stretches to fill the existing frame.

## Integration details

- Provider/style: `https://tiles.openfreemap.org/styles/liberty`, following the [OpenFreeMap quick start](https://openfreemap.org/quick_start/).
- Center and marker: `[72.9386134, 22.5483464]`, correctly ordered longitude then latitude, initial zoom 16.5.
- Marker uses the existing gold color token and displays the existing salon name. Popup text uses `setText`, not HTML interpolation.
- Zoom buttons, mouse dragging, keyboard controls and MapLibre cooperative gestures are enabled. Mobile pan/pinch uses two fingers so one-finger page scrolling remains available.
- OpenFreeMap, OpenMapTiles and OpenStreetMap attribution is visible and linked.
- `IntersectionObserver` defers renderer loading; `ResizeObserver` keeps the canvas sized to the frame. Disposal guards prevent initialization after unmount. Cleanup disconnects observers, clears the loading timer, removes the marker and removes the map.
- Loading failure shows a compact directions fallback inside the reserved panel. The left card and contact actions remain usable. Transient tile failures after the initial successful load do not cover the map.
- The MapLibre worker follows the official [Next.js/Turbopack installation guidance](https://maplibre.org/maplibre-gl-js/docs/#installation), serving the worker and shared module together locally.
- No Google Maps API, iframe, API key, environment variable, billing setup, Mapbox renderer, backend or extra state library was introduced. MapLibre itself contains some upstream `@mapbox/*` utility dependencies; `mapbox-gl` is not installed.
